# Eye Tracking Applications for E-Learning Purposes

## Overview
This project uses WebGazer.js to track a student's eye movements during online learning sessions. When distraction is detected, the system provides interventions such as quizzes to help regain focus.

## Features
- Real-time eye tracking using WebGazer.js
- Distraction detection
- Interactive quiz intervention
- Browser-based implementation
- User-friendly interface

## Technologies Used
- JavaScript
- HTML
- CSS
- WebGazer.js
- Node.js
- MongoDB

## Project Structure
- src/ : Application source code
- public/ : Static assets
- assets/ : Images and resources
- mongodb.js : Database connection
